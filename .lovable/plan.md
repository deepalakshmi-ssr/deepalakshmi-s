# Deepalakshmi Portfolio

## Goal
Build a complete premium, light-theme personal portfolio for Deepalakshmi S, using the uploaded DS logo for the opening sequence, the real portrait on About, and all three uploaded project images throughout the relevant pages.

## Pages and content
- Create dedicated Home, About, Projects, Achievements, Coding, and Contact pages.
- Add separate project stories for MOVA, HireReadyAI, and AGRIMATE at their requested URLs.
- Use only the supplied biography, education, skills, internships, awards, certifications, coding profiles, and contact information.
- Keep the portfolio professional and editorial rather than resembling a résumé template.

## Visual experience
- Establish an ivory, charcoal, muted emerald, and restrained champagne design system with strong editorial typography, fine grid details, thin rules, and soft depth.
- Build a short opening film using the uploaded DS logo, a light sweep, progress line, and working “Skip intro” control.
- Add a translucent sticky navigation, active-page treatment, polished mobile menu, shared footer, tasteful scroll reveals, project-image movement, and fast page transitions.
- Respect reduced-motion preferences and maintain clear contrast, keyboard access, and readable mobile layouts.

## Key sections
- Home: identity statement, calls to action, expertise strip, selected work, and current MOVA focus.
- About: uploaded portrait, biography and education, “How I Think” process, categorized skills, and experience.
- Projects: three large image-led entries with full detail pages covering problem, solution, operation, features, technology direction, status, and future scope.
- Achievements: editorial timeline of supplied awards, programs, and certifications.
- Coding: external cards for LeetCode, GitHub, and LinkedIn using the supplied facts and links.
- Contact: direct email, phone, and profile links only; no form or fake sending behavior.

## Technical details
- Implement within the existing TanStack Start application using TypeScript, Tailwind CSS, Lucide icons, and reusable React components.
- Store the uploaded media through the project asset flow, optimize display sizing, and derive the favicon from the DS mark.
- Add unique metadata for every page, semantic headings, descriptive image alternatives, secure external links, and responsive navigation.
- Verify the finished experience at desktop and mobile widths, including intro skipping, navigation, project links, external links, layout overflow, console health, and the final build signal.
